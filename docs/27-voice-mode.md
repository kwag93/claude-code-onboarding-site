# 27. 보이스 모드: 말로 코딩하기

2026년 3월, Claude Code에 공식 보이스 모드가 추가되었습니다. 이전에는 서드파티 도구(superwhisper, MacWhisper 등)가 필요했지만, 이제 `/voice` 한 줄이면 바로 음성 코딩을 시작할 수 있어요.

> **타이핑은 분당 40단어, 말은 분당 150단어.** 3.75배 차이가 생산성으로 직결됩니다.

---

## 시작하기

터미널에서 Claude Code를 실행한 후:

```text
/voice
```

이것으로 끝이에요. 보이스 모드가 활성화되면 welcome 화면에 안내가 표시됩니다.

!!! info "롤아웃 안내"
    보이스 모드는 점진적으로 배포 중입니다. 아직 접근이 안 된다면 Claude Code를 최신 버전으로 업데이트하고 기다려주세요.

---

## 두 가지 모드

| 모드 | 작동 방식 | 적합한 환경 |
|------|-----------|-------------|
| **Hands-Free** | 자연스러운 말 멈춤을 감지해 자동으로 듣고 응답 | 조용한 사무실, 재택 |
| **Push-to-Talk** | 스페이스바를 누르고 있는 동안만 입력 | 카페, 오픈 오피스 |

조용한 환경이면 Hands-Free, 주변 소음이 있으면 Push-to-Talk을 쓰세요.

---

## 음성 코딩이 특히 유용한 상황

### 1. 생각 정리가 안 될 때

코드를 보면서 "이거 어떻게 고치지?" 싶을 때, 타이핑으로는 생각이 정리가 안 되는 경우가 많아요. 말로 쭉 설명하다 보면 문제의 원인이 명확해지는 경험을 하게 됩니다.

```text
[음성] "이 인증 미들웨어가 가끔 토큰 검증에 실패하는데,
로그를 보면 토큰 자체는 유효해. 근데 타임존 관련해서
서버 시간이랑 토큰 발급 시간이 다를 수 있을 것 같은데,
그 부분 한번 확인해줘."
```

> 타이핑이라면 "토큰 검증 실패 원인 찾아줘"로 끝냈을 거예요. 말로 하면 자연스럽게 맥락이 풍부해집니다.

### 2. 복잡한 요구사항을 설명할 때

여러 조건이 얽힌 기능은 타이핑으로 구조화하기 번거로워요.

```text
[음성] "사용자가 결제할 때 먼저 쿠폰이 있는지 확인하고,
쿠폰이 있으면 할인율을 적용한 금액으로 결제하되,
최소 결제 금액 1000원 이하로는 내려가면 안 되고,
결제 성공하면 쿠폰을 사용 처리하고 실패하면 롤백해줘."
```

### 3. 여러 단계의 작업을 한 번에 지시할 때

```text
[음성] "먼저 users 테이블에 phone_number 컬럼을 추가하는
마이그레이션을 만들고, 그 다음에 프로필 편집 폼에
전화번호 입력 필드를 추가해줘. 유효성 검사도 넣어주고.
마지막으로 관련 테스트 코드도 작성해줘."
```

### 4. 손이 자유로워야 할 때

- 손목 터널 증후군이나 반복성 긴장 손상(RSI)이 있을 때
- 산책하면서 아이디어를 구현할 때
- 화이트보드에 그림을 그리면서 설명할 때

## 실전 팁

### 자연스럽게 말하세요

천천히 말하거나 인위적으로 끊을 필요 없어요. 평소 대화하듯 말하면 됩니다. 발음이 좀 틀려도 Claude가 맥락으로 알아들어요.

### 복잡한 요청은 나눠서

한 번에 너무 많은 걸 말하면 중간에 놓칠 수 있어요. "먼저 이것부터 해줘"로 시작하고, 결과를 확인한 후 다음 단계를 말하세요.

### 코드 리뷰에 활용

```text
[음성] "방금 만든 코드 전체를 리뷰해줘.
보안 이슈, 성능 문제, 엣지 케이스 누락이 있는지 확인하고
문제가 있으면 바로 수정해줘."
```

눈으로 코드를 보면서 입으로 리뷰를 요청하는 게 타이핑보다 훨씬 자연스러워요.

### 디버깅 세션

버그를 발견했을 때 증상을 말로 설명하면, 타이핑할 때보다 더 많은 맥락을 전달하게 됩니다.

```text
[음성] "이 페이지에서 스크롤하면 헤더가 깜빡이는 문제가 있어.
Chrome에서만 발생하고 Safari에서는 괜찮아.
개발자 도구로 보니까 스크롤할 때마다 리렌더링이 되는 것 같은데
useEffect 의존성 배열이 잘못된 건 아닌지 확인해줘."
```

## 텍스트와 음성 전환

보이스 모드 중에도 타이핑으로 전환할 수 있어요. 대화 컨텍스트는 그대로 유지됩니다.

| 상황 | 추천 방식 |
|------|-----------|
| 요구사항 설명, 브레인스토밍 | 음성 |
| 정확한 변수명, 경로 지정 | 텍스트 |
| 코드 리뷰 요청 | 음성 |
| 설정 파일 수정 | 텍스트 |

> 설명은 음성으로, 정밀한 지시는 텍스트로 — 이 조합이 가장 효율적이에요.

---

## 이전 서드파티 도구와 비교

| 항목 | 공식 보이스 모드 | 서드파티 (superwhisper 등) |
|------|-----------------|--------------------------|
| 설치 | `/voice` 한 줄 | 별도 앱 설치 + 설정 |
| 통합 수준 | 네이티브 (양방향 대화) | 음성 → 텍스트 변환만 |
| 응답 | 음성으로 들을 수 있음 | 텍스트로만 확인 |
| 비용 | Claude 구독에 포함 | 별도 비용 발생 가능 |

서드파티 도구도 여전히 유용해요. 특히 superwhisper의 로컬 처리 속도나, 특수 기술 용어 인식이 더 나은 경우도 있거든요. 상황에 맞게 선택하세요.

---

## 자주 묻는 질문

**Q: 한국어로도 되나요?**
공식적으로는 영어 우선 지원이지만, 실제로 써보면 한국어 인식도 상당히 잘 됩니다. 편하게 시도해보세요.

**Q: 사용량 제한이 있나요?**
음성 대화도 일반 사용량 제한에 포함됩니다. `/usage`로 확인하세요.

**Q: 대화 내용이 저장되나요?**
네, 음성 대화의 트랜스크립트가 대화 히스토리에 자동 저장됩니다.
