# 22. Remote Control - 어디서나 이어서 작업하기

로컬 Claude Code 세션을 다른 기기에서 이어서 쓰는 방법이에요.

---

## Remote Control이란?

책상 터미널에서 시작한 세션을 폰이나 다른 PC 브라우저에서 그대로 이어가는 기능이에요. 코드는 클라우드로 안 가고 **내 컴퓨터에서만 실행**되면서, 인터넷으로 원격 조작만 하는 방식이죠.

### 핵심 특징

- **어디서나 이어서**: 소파에서 폰으로, 회의실에서 다른 PC로 이어가기
- **로컬 환경 그대로**: MCP, 도구, 설정 모두 유지
- **네트워크만 있으면**: 같은 Wi-Fi 필요 없음, 인터넷이면 어디든

### 흐름

```
책상 터미널 (실행 중)
       ↓ /rc 입력
모바일 / 다른 PC / 웹에서 이어서 작업
```

---

## ⚠️ 중요: 요금제 제한

> **Pro/Max 플랜 전용이에요. Team/Enterprise는 사용 불가입니다.**

플랜 확인은 `claude.ai/code` 계정 페이지에서 할 수 있어요.

---

## 시작 방법

### 1. 새 세션으로 시작

```bash
claude remote-control

# 상세 로그 보기
claude remote-control --verbose

# 읽기 전용 샌드박스 모드
claude remote-control --sandbox
```

### 2. 이미 열린 세션에서 활성화

```
/rc
```

(`/remote-control`도 동일)

### 3. 다른 기기에서 접속

**QR 코드** (제일 빠름)

```
스페이스바 → QR 코드 표시 → 폰 카메라 스캔 → Claude 앱 열림
```

**모바일 앱**: Claude 앱 → "Remote" 또는 "세션" 탭 → 활성 세션 탭

**PC 브라우저**: `claude.ai/code` → 좌측 "내 세션" → 원격 세션 선택

**세션 URL 직접 입력**

```
https://claude.ai/code?session=abc123def456
```

같은 Wi-Fi 안 써도 돼요. 인터넷만 있으면 어디서든 접속됩니다.

---

## 모든 세션 자동 활성화

매번 `/rc` 치기 귀찮으면:

```bash
/config
```

`"Enable Remote Control for all sessions"` → `true`

이후엔 새 세션마다 자동으로 원격 접속이 켜져요.

---

## 연결 및 보안

### 안전한 이유

- 인바운드 포트 안 열어요 → 방화벽 설정 건드릴 필요 없음
- 모든 트래픽은 TLS 암호화
- 세션마다 임시 토큰 발급 (재사용 불가)

### 네트워크 끊기면

10분 안에 복구되면 세션 살아있어요. 10분 넘으면 자동 종료되고 새로 시작해야 해요.

---

## Remote Control vs 웹 Claude Code

| 항목 | Remote Control | 웹 Claude Code |
|------|---------------|----------------|
| **실행 위치** | 내 컴퓨터 | Anthropic 클라우드 |
| **로컬 MCP** | ✅ | ❌ |
| **도구 접근** | ✅ 전부 | ❌ 제한 |
| **언제** | 진행 중인 작업 이어갈 때 | 새 작업 빠르게 시작할 때 |
| **요금제** | Pro/Max | 전 플랜 |

MCP 쓰거나 이미 터미널에서 실행 중이면 Remote Control, 그냥 새 대화 시작하는 거면 웹이 더 편해요.

---

## 제한 사항

- **원격 세션은 하나만**: 새 원격 세션 시작하면 기존 것 자동 종료
- **터미널 닫으면 끝**: Remote Control 실행 중인 로컬 터미널 유지 필수
- **10분 오프라인**: 네트워크 10분 이상 끊기면 세션 자동 종료

---

## 활용 시나리오

**출퇴근 중 모니터링**

집에서 장시간 빌드 돌리면서 `/rc` 켜두면, 출근길 폰으로 진행률 보고 간단한 수정도 가능해요. 사무실 도착하면 PC 브라우저에서 그대로 이어가면 됩니다.

**회의 중 즉석 검증**

"이게 실제로 되나요?" 하는 순간, 폰으로 세션 열어서 코드 바로 돌리고 결과 보여줄 수 있어요. 책상 PC는 백그라운드에서 계속 돌아가고요.

**팀원과 같은 세션 보기**

팀원 A가 로컬에서 원격 켜두면, 팀원 B가 브라우저로 같은 세션 접속해서 같이 볼 수 있어요. 단, 조작은 한 번에 한 명만 가능합니다.

---

## 트러블슈팅

### "세션 접속 불가"

순서대로 확인해보세요:
1. 로컬 터미널 열려 있는지
2. 네트워크 상태
3. VPN 쓰면 방화벽 확인
4. Pro/Max 플랜인지

### 자동 끊김

컴퓨터 슬립 모드가 제일 흔한 원인이에요. 슬립 해제하고 네트워크 재연결하면 대부분 해결돼요. 10분 넘게 끊겼으면 새 세션 시작해야 합니다.

### QR 코드 안 뜸

```bash
clear
claude remote-control --verbose
```

---

## 팁

**여러 프로젝트 동시에**: 프로젝트 A 터미널에서 원격 켜두고, 프로젝트 B는 별도 탭에서 로컬로 작업하면 돼요. 원격은 한 번에 하나만 활성화지만, 로컬 세션은 탭 여러 개 열어도 됩니다.

**모바일 즐겨찾기**: Claude 앱에서 원격 세션 즐겨찾기 해두면 다음번엔 바로 접속돼요.

**장시간 작업에 딱**: 30분짜리 스크립트 돌릴 때 Remote Control 켜두면, 밖에서 진행률 확인하고 끝나면 어디서든 결과 처리할 수 있어요.

---

## 보안 체크리스트

민감한 작업이라면:

- [ ] 공용 Wi-Fi에서 중요 코드 작업 안 하기
- [ ] API 키 등 민감 정보 터미널에 노출 안 되도록
- [ ] 작업 끝나면 Remote Control 종료 확인
